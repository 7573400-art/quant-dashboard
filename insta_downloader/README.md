# 인스타 다운로더 (광고 없음)

insget 처럼 인스타그램 게시물·릴스 링크를 붙여넣으면 동영상을 내려받는 웹앱입니다.
스마트폰에서 **홈 화면에 추가**하면 일반 앱처럼 쓸 수 있습니다 (PWA).

## 기능
- 링크 붙여넣기 → 썸네일·길이·화질 확인 → 다운로드
- 여러 장짜리(캐러셀) 게시물은 동영상마다 따로 다운로드
- `?igsh=` 같은 추적 파라미터 자동 제거, 링크가 섞인 텍스트도 인식
- 모바일에서는 공유 시트가 열려 **"동영상 저장"으로 갤러리에 바로 저장**
- 안드로이드: 앱 설치 후 인스타그램 앱의 **공유 → 인스타저장** 으로 링크 바로 전달
- ffmpeg 가 있으면 최고 화질(영상+음성 병합)로 받음
- 다크 모드 지원, 광고·추적 없음

## 실행
```bash
cd insta_downloader
pip install -r requirements.txt
python app.py          # http://localhost:8000
```

휴대폰에서 쓰려면 같은 Wi-Fi 에서 `http://<PC의 IP>:8000` 으로 접속하거나,
Render/Railway/Fly.io 같은 서버에 올리세요. (PWA 설치·공유 기능은 HTTPS 에서만 동작합니다.)
운영 환경에서는 `gunicorn -w 2 -b 0.0.0.0:8000 app:app` 로 실행하는 것을 권장합니다.

## 로그인이 필요한 경우
인스타그램은 비공개 계정이나, 요청이 많은 서버 IP 에 대해 로그인을 요구합니다.
브라우저 확장(예: "Get cookies.txt LOCALLY")으로 instagram.com 쿠키를 Netscape 형식으로 내보낸 뒤:
```bash
INSTA_COOKIES=/path/to/cookies.txt python app.py
```
쿠키 파일은 계정 비밀번호와 같으므로 절대 공유하거나 커밋하지 마세요.
